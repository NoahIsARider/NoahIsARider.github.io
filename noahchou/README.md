# noahchou

The landing page for **Noah Chou** — seven chibi selves, one door each.

- Live: <https://noahisarider.github.io/noahchou/>
- Mirror: <https://noahisarider.codeberg.page/noahchou/>

| File | What |
|---|---|
| `index.html` | the page — single file, also holds the inline SVG icon sprite and the JSON-LD block |
| `style.css` | Notion-ish paper look, light by default with a dark-mode toggle that remembers your choice |
| `app.js` | the seven "selves" (code / research / writing / music / film / games / contact) and the doors behind them |
| `assets/` | the chibi avatar PNGs, from [`NoahIsARider/personal-cartoon-avatar-assets`](https://github.com/NoahIsARider/personal-cartoon-avatar-assets) |

No build step, no trackers, no dependencies, no absolute paths — edit the three files and push.

Canonical URL: <https://noahisarider.github.io/noahchou/>
