项目

从我的 GitHub 里挑出来的一组项目，按各自要解决的问题分组。

大模型与多智能体

  • MatchaFlow — 一个跑完整软件项目流程的大模型多智能体系统，状态存放在共享数据库里，不在对话记录里。
  • Crusaders — 一套人机团队的脚手架，权力可以动态交接。把角色和指标声明一次，之后逐步测量谁该握住控制权。
  • DLFaceDetection — 一个 gRPC 人脸识别系统，模块会在运行时按实时 CPU 负载和网络延迟在节点之间迁移。

医疗 AI

  • Open Stethoscope — 一个 404K 参数的心脏杂音检测器，覆盖四个听诊点，小到能装进诊所的笔记本，用官方 PhysioNet-2022 指标打分。

商业与推荐

  • ZhituCareer — 一个职业副驾，大模型智能体与实时招聘抓取喂给匹配和课程推荐引擎，一条 docker compose up 就能跑起来。
  • Bigdata-Final-System — 用信令数据做商户选址，实时的 Flink 与 HBase 链路和离线的 Spark 与 ClickHouse 链路共用一套空间模型。
  • MankiwEcoLab — 曼昆教材里从生产可能性边界到菲利普曲线的每一个核心模型，都变成可运行、可扰动、带 204 个测试的 Python。
  • RecRedTeam — 面向大模型购物智能体的红队审计，威胁分类映射到 OWASP ASI 2026，附攻击库、双通道评审和排行榜。

社会计算

  • AIFrameQuest — 一个当作仪器用的社区平台，FAISS 图像相似度和评分数据被拿来通过鲍德里亚读一遍。
  • Reptile — 一套抓取接口，每个站点一个适配器，覆盖片单、弹幕与新闻页。
  • OnChainGov — 一条链上治理工具链，采集 Snapshot、Tally、EVM 与 Steemit 的数据，再做 DID、PSM-DID、安慰剂与事件研究估计。
